# الخرائط الموضوعية — HTML5 الإصدار السادس

## الجديد
- عرض غامر: تختفي الأشرطة العلوية والسفلية عند تفعيل ملء الشاشة.
- نقرة قصيرة واحدة على مساحة الشريحة غير التفاعلية تُظهر الأشرطة مؤقتًا، وتختفي بعد 3 ثوانٍ.
- النقر والسحب والتكبير بإصبعين معاملات مختلفة؛ لا يسبب تحريك شريحة مكبرة انتقالًا.
- زر صغير شبه شفاف أعلى اليسار يمكنه إظهار أدوات الخروج من ملء الشاشة عند الحاجة.
- عارض الفيديو الموجود في الشريحة الخامسة ومفتاح ملء شاشة الفيديو ما زالا موجودين.
- اختصار الدخول إلى ملء الشاشة يخضع لدعم المتصفح، وقد لا يخفي أشرطة النظام في بعض الأجهزة.

## النشر عبر GitHub Desktop
استبدل الملفات السابقة بمحتويات هذا المجلد، ثم Commit to main وPush origin. لن يتغير رابط GitHub Pages.

## الاختبار
1. افتح الموقع من الهاتف في الاتجاه الأفقي.
2. اضغط ملء الشاشة: ينبغي اختفاء شريطي أدوات الموقع.
3. انقر نقرة قصيرة على مساحة غير تفاعلية: تظهر الأدوات مؤقتًا.
4. جرّب السحب يمينًا، والتكبير بإصبعين، والتحريك بعد التكبير.
5. في الشريحة الخامسة تحقق من الفيديو وزر ملء شاشة الفيديو.

تنبيه: الصور مأخوذة من PDF المرفق، وبعض التفاصيل النصية صغيرة أصلًا في تصميم المعلم. يستلزم فتح Wordwall وYouTube وGoogle Earth الاتصال بالإنترنت والسماح بها عبر سياسات التابلت.
